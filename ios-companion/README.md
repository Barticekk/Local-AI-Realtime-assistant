# AI Glasses iOS Companion App

A native SwiftUI companion app (iOS 16.0+) that bridges DIY AI glasses hardware
with an AI backend server.  
Bundle ID: `com.barticekk.localairealtimeassistant.companion`

## How to open in Xcode

> ⚠️ A full `.xcodeproj` / `.xcworkspace` is not yet committed because it must
> be generated by Xcode or `xcodegen` with real signing values.  
> Follow the steps below to create the project locally.

### Prerequisites

- macOS 13+ with **Xcode 15+** installed
- Apple Developer account (free or paid)
- (Optional) CocoaPods if you add third-party pods later

### Steps

1. **Open Xcode → File → New → Project**
   - Template: **App** (under iOS)
   - Product Name: `CompanionApp`
   - Bundle Identifier: `com.barticekk.localairealtimeassistant.companion`
   - Interface: **SwiftUI**
   - Language: **Swift**
   - Minimum Deployments: **iOS 16.0**
   - Save into: `ios-companion/`

2. **Add the source files**
   - Drag all files from `ios-companion/CompanionApp/` into the Xcode project
   - Ensure "Copy items if needed" is NOT checked (files are already in place)

3. **Replace the generated Info.plist** with `Resources/Info.plist`  
   (or copy the permission keys into the Xcode-generated one)

4. **Build & Run** on a physical device or simulator (`⌘R`)

## How to configure the AI backend endpoint

The backend URL defaults to `https://your-backend.example.com`.

**At runtime (development):** open the app → tap **Settings** → edit *Base URL*.

**Permanently:** change `AIBackendClient.defaultEndpoint` in
`Services/AI/AIBackendClient.swift` before building:

```swift
static let defaultEndpoint = "https://api.yourserver.com"
```

### Expected backend API contract

```
POST /command
Content-Type: application/json

Request:
{
  "text": "call John",
  "session_id": "optional-session-uuid"
}

Response (200):
{
  "action": "call_contact",
  "target": "John",
  "payload": null
}
```

Supported `action` values: `call_contact`, `music_play_pause`, `music_next`,
`music_previous`, `open_url`.  
Unknown values are safely ignored.

## How to run a Codemagic build

1. **Create the app** in [App Store Connect](https://appstoreconnect.apple.com)
   with bundle ID `com.barticekk.localairealtimeassistant.companion`.

2. **Generate an App Store Connect API key**  
   App Store Connect → Users & Access → Integrations → API Keys.

3. **Add variable groups** in Codemagic UI  
   (Application → Environment variables):

   | Group | Variable | Value |
   |---|---|---|
   | `app_store_credentials` | `APP_STORE_CONNECT_ISSUER_ID` | Issuer ID from API key page |
   | `app_store_credentials` | `APP_STORE_CONNECT_KEY_IDENTIFIER` | Key ID |
   | `app_store_credentials` | `APP_STORE_CONNECT_PRIVATE_KEY` | Contents of the `.p8` file |
   | `certificate_credentials` | `CERTIFICATE_PRIVATE_KEY` | Your distribution certificate private key |

4. **Set `APP_STORE_APP_ID`** in `codemagic.yaml` to the numeric app ID from
   App Store Connect → App → General → App Information.

5. **Update workspace / scheme vars** in `codemagic.yaml` once the Xcode
   project is committed:
   ```yaml
   XCODE_WORKSPACE: "ios-companion/CompanionApp/CompanionApp.xcworkspace"
   XCODE_SCHEME: "CompanionApp"
   ```

6. Push to `main` — Codemagic triggers automatically and builds + signs the IPA.

## iOS limitations and constraints

### What works on App Store iOS

| Feature | How |
|---|---|
| BLE glasses connectivity | CoreBluetooth — requires Bluetooth permission |
| Phone call initiation | `tel://` URL — iOS shows confirmation sheet |
| Media play/pause/next/prev | MPRemoteCommandCenter (active app) |
| Open URLs / deep links | `UIApplication.open(_:)` |
| Backend HTTP/HTTPS requests | URLSession (foreground + background with config) |

### What does NOT work silently on iOS

| Feature | Reason |
|---|---|
| Silent automatic phone dialling | Apple policy — confirmation always shown |
| Always-on background AI agent | iOS suspends apps; background modes are specific |
| Arbitrary control of other apps | iOS sandbox — no inter-app automation without shortcuts/intents |
| Reading all notifications | Only notifications your app or specified notification service sends |

### Background mode guidance

Enable only what you need in `Info.plist → UIBackgroundModes`:

- `bluetooth-central` — needed if BLE must reconnect while the app is in the background
- `audio` — needed if the microphone must capture audio in the background
- Do **not** add modes speculatively — Apple will reject the app
